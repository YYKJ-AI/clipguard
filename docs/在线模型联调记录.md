## 初测发现与修复

1. DeepSeek 对“不要删除 clip-a，只把它缩短一秒”返回最终时长 3000 ms，正确值应为 4000 ms。新增相对裁剪字段 `shorten_by_ms`，要求模型只转换缩短量的单位，由 Go 在组合操作的工作副本中逐项相减；保留 `duration_ms` 表示明确指定的最终时长，两者互斥。补充否定句与数值提示。不能将本次提示优化视为所有语义错误均已消除。
2. DeepSeek 对未知 ID 返回没有候选项的澄清，没有明确说明拒绝。提示改为明确未知 ID 返回 unsupported，禁止替换目标。引擎原有未知 ID 校验仍独立执行。
3. 智谱 HTTP 429：程序返回错误与改写/离线提示，工程不变；没有自动切换到另一家服务，也没有无上限重试。低频复测仍限流，保留阻塞结果。

新增自动化回归覆盖相对裁剪单步、重复步骤、绝对再相对、无效量、互斥参数、其他操作误带字段、非法类型以及第二项失败时无部分修改；模型参数测试核对 thinking 和 token 上限的实际请求体，非法设置不会发起请求。

## DeepSeek 修复后复测

14 项全部通过：中文数字自由表达；裁剪/移动/字幕/删除组合；连续相对裁剪；否定删除后缩短一秒；多轨歧义及选定后碰撞；信息缺失及补充；锁轨拒绝；第二项失败原子性；删除取消；素材源越界；未知 ID 拒绝；指令不能绕过确认；缺少单位需澄清；字幕正文中的“第二段”与目标歧义区分。

测试在确认前比较预期目标、字段和新值，验证预览阶段工程未改变；需要提交的场景再核对实际结果、版本和整体撤销。拒绝、澄清和取消场景核对工程未变化。初测中错误的缩短数值只发生于独立虚构工程，原始失败记录予以保留。
