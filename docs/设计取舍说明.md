# 安全剪辑 Agent：设计取舍说明

更新：2026-11-12。范围：独立可移植的虚构 JSON 时间轴，离线解析为验收主路径。

## 解析与执行隔离

离线规则或可选模型仅输出候选操作、澄清或不支持。Go 编辑引擎独立检查操作类型、字段、目标、轨道、时间和素材边界，不执行模型输出的代码或命令。这样，更换解析器不改变确定性的编辑规则；模型理解错误也不能绕过校验与确认。

## 时间语义与原子性

时间为整数毫秒，区间左闭右开。同轨不重叠，跨轨可重叠；碰撞时拒绝，不自动推移。时间线起点决定片段出现位置，素材入点决定从源素材何处取内容。右端裁剪保持两者不变，时长不能超过源素材剩余长度。视频编辑不自动移动字幕。

单条指令按顺序在副本中验证，中间步骤非法即整条拒绝。中间操作允许没有净变化，以便继续计算后续操作；完整计划没有实际变化则拒绝。预览和提交使用同一次计算结果，报告根据实际提交前后差异产生。

## 防止误操作

歧义先列候选，由用户选择；选择绑定操作目标，不替换字幕正文。不支持或无效请求保持本条指令未提交，说明原因并提示改写完整指令。轨道锁定字段必须明确为布尔值，片段必填时间不得省略或为空；非法导入不能替换当前工程或清空计划和历史。

预览绑定工程 ID、revision 和加载标识，确认时在锁内再次检查；切换、重载或其他提交后，旧计划失效。删除同样必须明确确认；取消不修改工程。一次提交只推进一个版本。

## 撤销与保存

撤销保存实际提交前的完整快照，一次恢复整条指令，同时推进版本并使旧计划失效。重复撤销请求不能消费下一条历史。状态与历史保存在进程内存，运行期间可连续使用；导出 JSON 由用户保存，重启或重载前需注意历史会丢失。这一取舍满足本地任务，不引入数据库。

重做恢复撤销时保存的确定状态，不重新解释自然语言；新编辑清空重做分支。记录独立保留已提交的实际 Diff、动作和版本，取消或失败不记为成功。插入只读复制工程中已有片段，分配新稳定 ID，仍受源区间、同类型轨道、锁轨和碰撞约束，不自动推移。

差异用同一比例显示修改前后时间区间。简单媒体绑定留在浏览器，不上传、不混入 JSON；使用内嵌虚构封面可无素材演示。默认无密钥可运行，在线配置由每个运行者提供；协议连接检查不等于语义全面适配。

## 限制与未完成范围

离线模式仅支持 README 公开句式，不能承诺任意自然语言；真实供应商兼容性和自由表达效果需分别验收。未实现视频编码导出、字幕识别、自动分镜、云存储、音频联动及跨重启恢复。简单预览不做多视频合成。附加产品接口不代表真实产品集成完成。跨平台与竞态检查工作流已提供，云端通过状态以实际 Actions 运行结果为准。

核心模块对应 engine.go、parser.go、workspace.go、server.go；项目运行依赖为 Go 标准库及原生浏览器能力，第三方候选组件的调研与实际复用边界见 README 及开源选型文档。
