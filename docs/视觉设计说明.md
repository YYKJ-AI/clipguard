# 视觉设计说明

日期：2026-11-11。依据用户确认的方向：现代文创、浅米白、青绿色、轻盈留白，产品名称保留“安全剪辑 · 指令工作台”。参考文藏（wenzang.cn）的文化内容组织方式与截图中的留白式工作台布局，未复制其图片、标志或源码。

## 页面取舍

- 用固定侧栏承载“创作工作台、工程与时间轴、剪辑助手、操作说明”，让客户先理解工作路径，再进入指令操作。
- 首屏用短标题“让灵感成章，让剪辑从容”，搭配低对比渐变和自绘时间轴纸张插画，保留文创气质，不引入外部图片依赖。
- 采用浅米白页面、白色卡片、青绿色主按钮；字幕片段用暖金色区分，锁定状态保留纹理提示。文字颜色使用墨绿色，避免纯黑造成生硬感。
- 编辑区仍保持“先预览、再确认”的视觉层级；危险删除使用暖棕色提示，不用大面积红色破坏整体气质。
- 空状态明确展示“加载演示工程”和“导入 JSON”。加载后时间轴和片段明细保持原有结构，只调整卡片、标题和间距。
- 手机端折叠侧栏为横向导航，主区域单列排列；时间轴只在自身容器内横向滚动，页面不产生整页横向溢出。按钮和输入字号在窄屏提高，便于触摸。

## 验证

最终页面在 1366×768、1440×1000、1024、768、390×844、320 宽度检查；18 项浏览器检查通过，包括首屏入口、模型咨询、演示工程、预览确认、撤销、取消删除、锁轨、原子性、导出导入、刷新、手机时间轴滚动和侧栏锚点导航。截图和机器结果位于 `output/design/`。
