### 冻结规则

- 只保留现有四类编辑操作：移动、视频右端裁剪、字幕文字/时间调整、删除。
- 裁剪不改变片段起点和素材入点；不新增片头裁切、中间挖除或自动波纹推移。
- 同轨不能重叠，碰撞拒绝；锁定轨道不能修改。
- 视频变化不自动带动字幕；音画字幕联动不在本期实施。
- 模型只产生候选计划，不能执行代码、命令或直接提交工程。
- 必须预览、明确确认、整体提交；失败不能部分生效。
- 保留工程/版本/加载标识绑定、处理期间变化检查、整体撤销及重复请求保护。
- 发现必须改变冻结语义才能解决的问题，单独报告，获确认前不修改。

## 三、技术栈与实现方式

| 层面 | 当前使用的技术 | 用途 | 说明 |
| --- | --- | --- | --- |
| 核心后端 | Go，`go.mod` 声明最低 1.22 | 校验、预览、版本保护、提交、撤销 | 仅标准库，无第三方 Go 模块 |
| 本地 HTTP 服务 | Go `net/http` | 接收页面请求、返回状态和工程结果 | 默认本机 8090；端口可配置 |
| 离线理解 | Go `regexp`、字符串处理、规则解析 | 识别公开句式、指代、位置、组合操作和候选目标 | 有限解析器，不承诺任意自然语言 |
| 可选在线理解 | HTTP Chat Completions 协议 | 模型返回咨询、澄清、计划或不支持 | 已使用指定网关及 `dashscope/qwen-plus`；由服务端环境变量配置 |
| 结构化约束 | `encoding/json`、严格字段白名单 | 拒绝未知字段、错误类型、非法操作 | 不把模型文字直接当作可执行内容 |
| 时间轴引擎 | 自行实现的 Go 校验与副本计算 | 检查目标、锁轨、时间、源区间及碰撞 | 全部操作通过后才允许提交 |
| 状态保护 | `sync.Mutex`、`revision`、加载标识 `epoch` | 防止旧计划、重复提交及状态覆盖 | 工程/版本/加载标识共同绑定计划 |
| 撤销 | 内存快照、历史栈、撤销请求标识 | 恢复上一条完整指令前的工程 | 不是让模型猜测恢复方案；不跨程序重启保存 |
| 页面 | 原生 HTML、CSS、JavaScript | 工程展示、输入、预览、确认和反馈 | 无前端框架、无 npm 运行依赖 |
| 自动化验证 | Go `testing`、`httptest` | 核心流程、HTTP 接口及模型模拟 | 模拟模型测试不调用外部服务 |
| 界面逻辑测试 | Node.js 内置测试工具 | 名称展示、动态示例等脚本行为 | 仅开发验证使用，无额外 npm 依赖 |
| 浏览器验证 | Playwright CLI + 本机 Edge | 页面展示和真实用户操作路径 | 仅开发工具，不是程序运行依赖 |

密钥只经服务端运行环境注入，不写进源码、页面、配置文件或本文件。旧直连供应商密钥禁止使用。列出云端模型配置不代表真实模型效果已经全面验收。
