# 扩展能力与可移植交付

日期：2026-11-12，北京时间。本轮由项目所有者明确要求逐项实现任务书缺口，并补充“其他人从 GitHub 拉取后也能验收”；随后明确本次暂不提交 GitHub。

## 当前交付范围

| 原缺口 | 本轮实现 | 验收边界 |
| --- | --- | --- |
| 前后可视化差异 | 同一时间比例的修改前/后条块、逐项字段差异、取消清除视图 | 来自同一引擎 Diff，预览不提交 |
| 编辑记录 | 独立的已提交记录、动作、时间、版本、实际差异；刷新读回 | 进程内存，重载/重启清空；取消/失败不记成功 |
| 重做 | 快照恢复整条指令；新编辑清空分支；版本推进与重复请求保护 | 不重新解析自然语言；本地与可选产品接口均支持 |
| 简单媒体预览 | 内嵌原创封面、本地视频/图片绑定、素材入点、右端停止、独立字幕叠加 | 绑定留在浏览器，不上传、不写入 JSON；不做多轨合成或混音 |
| 片段插入 | 表单和离线句式复制已有视频/字幕，生成新 ID，预览确认和整体撤销/重做 | 不生成新素材，不波纹推移；来源只读，目标同类型且未锁定 |
| 在线模型状态 | 未配置/待适配/已连通/暂不可用；真实 JSON+SSE 连接检查 | 本地模拟验证协议逻辑；真实供应商由运行者配置并单独验收 |
| 对方可独立验收 | 跨平台启动脚本、内嵌样例、无密钥默认、验收指南、CI/发布包工作流 | 不需要提交者电脑、账号、私有网关或素材；本次不推送 |

## 安全语义

保留右端裁剪、不自动带字幕、同轨碰撞拒绝、锁轨保护、严格操作字段、按序工作副本、原子提交、明确确认及工程/版本/加载标识绑定。扩展插入只新增受限数据操作，不执行代码或命令。

每次 edit/undo/redo 只推进一个版本并记录真实 Diff。编辑记录最多 1000 条、撤销深度最多 100 条，达到上限明确拒绝。媒体绑定完全独立于服务端项目；未绑定素材仍能完成任务书 JSON 验收。

## 验证记录

测试先以缺失能力失败，再实现并回归。新增覆盖：插入视频/字幕、重复 ID、未知来源、负时间、跨类型、锁轨、碰撞、额外字段、批量第二项失败；记录只包含实际提交；整条重做、顺序、重复请求、分支清空、重载/会话/用户隔离；连接检查普通 JSON、SSE、未配置与 429。

真实浏览器已验证 35 项主流程及 5 项真实视频检查：包含原有安全路径、前后差异、编辑记录刷新、撤销/重做、插入、实际下载后再导入、外部 ID 及乱序、360px/600px；页面脚本异常为 0。媒体视频由浏览器临时生成，未使用外部素材，验证了素材入点 400ms、时间轴 500ms 对应源 900ms、片段右端停止和绑定不进入 JSON。

从干净交付目录实际运行：Go 测试 200 项通过（含子测试），0 失败，2 个包通过；`go build ./...`、`go vet ./...` 通过；Node 页面逻辑 17/17、脚本语法检查通过。Windows PowerShell 离线启动脚本已从该目录实际构建并启动。Linux/amd64 与 macOS/arm64 已本地交叉构建成功，未在对应系统主机运行。

最终程序真实浏览器主流程再次 35/35 通过，真实视频路径另验 5 项。开发阶段与最终交付目录分别运行，不混用旧 exe。清洁目录没有开发者绝对路径、私有网关或真实模型密钥依赖。GitHub CI 未触发，因为项目所有者要求本次暂不提交。

浏览器 422/409 是主动验证锁轨、非法时间与旧计划导致的预期 HTTP 拒绝，不宣称所有控制台网络记录为空。验收脚本只替换原生的导入/重载提示以允许自动化继续，不模拟编辑 API 或模型来替代真实 Go 引擎。

## 文件导航

- `internal/agent/engine.go`：insert 结构白名单与独立校验。
- `workspace.go`：确定性历史、记录、撤销与重做。
- `parser.go`：离线插入、选择引用及组合。
- `server.go`、`product.go`：记录与重做接口，插入预览。
- `model_status.go`、`extension_model.go`：协议检查与扩展能力说明。
- `web/`：前后对比、记录、插入、重做、媒体预览及内嵌封面。
- `scripts/`、`.github/workflows/`：跨平台运行及自动化交付。

## 保留边界

真实云端模型语义与供应商兼容性未在本轮用真实密钥验证；“已连通”只说明两种协议检查成功。没有跨重启存储、外部编辑器连接、音频联动、自动字幕、画面检测修复或视频成片导出。这些平台级能力不作为任务书五项扩展已完成的依据。

GitHub Actions 和各平台发布包构建已配置，本次没有推送触发远程检查，不声称已经在 macOS/Linux 主机实际运行。Go 1.22 最低版本及竞态检测以未来 CI 真实结果为准。
