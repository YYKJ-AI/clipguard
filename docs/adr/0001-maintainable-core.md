# 0001：以现有编辑内核为边界进行规范化

日期：2026-11-12。状态：采纳。

## 背景

项目是本地内存时间轴编辑器，已有离线解析、可选模型、人工确认与撤销。本次重构消除重复实现与边界缺陷，同时保留左闭右开、同轨不重叠、右端裁剪、不自动推移、字幕独立和整条指令原子提交。

## 决策

- 保留一个 `internal/agent` 包，按职责拆文件，避免为了目录图增加跨包转换、类型别名与循环依赖。路由在 `server.go`，对话编排在 `dialog.go`，会话在 `session.go`，解析规则在 `grammar.go`，目标定位在 `target_resolver.go`。
- 五类操作各一个 `op_*.go` 文件，在 `operations.go` 显式注册。注册项同时提供允许字段、执行函数和说明；严格解码、执行和模型提示读取同一注册表。不使用 `init` 隐式注册。新增操作仍需定义句式及测试，不承诺任意新语义只改一处。
- 能力限制及咨询文案在 `capability.go` 集中管理，供模型提示和回复归一化使用；传输层不再维护能力长文本。
- 深拷贝显式复制每个指针字段，不进行 JSON 往返。新增可变字段时同步更新拷贝函数与隔离测试。Diff 按 ID 建索引，保留原输出顺序。
- 待确认计划只保留独立操作、差异与工程绑定；在同一互斥锁中检查绑定、重新计算并提交。撤销仍用快照，不引入事件溯源。
- `Config.Now` 注入会话时钟，工作区使用同一时钟记录时间；计时日志使用真实单调时钟。
- 会话在请求到来时清理默认 30 分钟空闲项，满容量移除最久未访问项。单连接来源每分钟最多创建 20 次；限流表也过期并有容量上限，不信任客户端的转发 IP 头。没有活跃请求时不启动定时后台线程，内存保持有界。
- 会话回收不代表落盘。页面与 README 说明未导出工程会丢失；产品身份接口的工程不参与匿名浏览器会话淘汰，保留原容量拒绝规则。
- 前端使用原生模块和单个显式状态对象，按时间轴、预览、媒体、历史、对话与控件分工；没有构建器、框架或运行时依赖。候选在响应中保留完整有界列表，在页面按 20 项分页，任意页均可选择；没有引入额外的服务端分页协议。
- 错误使用 `AppError` 和稳定错误码，内部诊断不参与字符串匹配。未知错误只展示通用提示；请求日志不记录正文、模型输出、密钥或会话 Cookie。

## 未采用的方案

- 四套 Store 接口、Executor、Redis、数据库：目前只有内存实现，且事务必须横跨工程、计划与历史。提前拆成多个存储接口会使原子性更难维护。真实持久化或外部剪辑器需求出现时，再按其事务能力抽取边界；现有 `Parser`、`Authenticator`、`ProjectCodec` 保留。
- 第二个 LegacyCodec：`examples/timeline3.json` 与默认样例使用同一格式，重复实现没有兼容收益。现有产品测试已用另一种包裹格式验证 Codec 可替换性。
- 全面改名 Intent/Effect、改成三个解析结果接口、强制拆成十个包：没有改善当前用户可见行为，会造成大范围兼容修改。解析结果保留统一校验入口与状态约束。
- 全量时间字段类型迁移：当前 JSON、操作指针、测试与网页都以整数毫秒交互。暂保留 DTO，依靠源时间约束、溢出及边界测试锁定语义；接入外部时间基准时再引入领域类型与显式转换。
- 增量校验：保留逐操作全量校验，保证中间非法状态不能越过原子性约束。先用 4096 片段基准评估，再决定索引与增量校验的复杂度是否值得。

## 后续修改规则

行为修改先补可失败的回归测试；重构使用现有行为测试保护。新增操作须覆盖解码、锁轨、时间、原子性和提示说明。不要仅修改文档来掩盖实现不一致。只有引入实际第二种实现或外部边界时才增加接口。
