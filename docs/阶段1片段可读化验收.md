# 阶段 1：片段可读化验收

日期：2026-11-11

## 修改范围

- `Clip` 增加可选 `display_name`，名称最多 128 个 Unicode 字符；稳定 `id` 仍是编辑身份。
- 旧格式工程无需修改即可导入；名称字段在导出、编辑和撤销后保留。
- 时间轴、片段明细、预览和操作示例使用可读名称与分:秒时间。
- 示例根据当前工程和轨道内时间顺序动态生成，不再固定依赖 `clip-a`、`caption-lock`。
- 不适合直接写入离线句式的特殊片段 ID 不生成示例，避免把 ID 作为命令语法解释。
