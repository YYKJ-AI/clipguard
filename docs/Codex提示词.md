## 本期四个阶段（严格按序，逐级验收）

1. **片段可读化**：`Clip` 增加可选 `display_name`（≤128，可省略，旧 JSON 无条件兼容）；界面显示名称 + 可读时间；示例指令动态生成，不依赖固定 `clip-a`。
2. **自然语言增强**（离线可验证）：支持"这段""第二个镜头""刚刚那个字幕""在两个片段之间"；"在 A 和 B 之间"无法确定时澄清不猜测；多轮澄清只问缺失项，改口作废旧意图；否定句只取正向操作。
3. **反馈分层与界面**：六种状态区分（咨询/需补充信息/待确认/已执行/执行失败/**识别了但当前不支持**）；错误全部转成用户能懂的中文；单角色"剪辑助手"悬浮功能说明且与实际能力一致；窄面板（600px 内可用）；浅米白+青绿+留白。
4. **回归扩充与交付记录**：既有 124 个测试必须继续全绿；新增打乱顺序/同名/指代/否定/改口/组合/跨工程隔离用例；更新 README 与验收报告。

上一阶段验收不通过不进入下一阶段。

## 本地可验证的回归红线（每阶段必测）

1. **禁止"只给建议不执行"还显得在干活**：识别了但当前未接通的需求，必须明确回复"暂时不支持，原因是 X"，禁止用操作建议冒充执行结果。
2. **素材定位顺序确定性**：本地用打乱 JSON 数组顺序、同名片段、多轨场景验证"第二段"等定位不受影响；界面顺序、候选顺序、模型可见顺序同源。
3. **操作结果如实**：报告必须与最终时间轴一致；失败必须明说哪项失败、整条未生效。
4. **禁止推用户去手动操作**：不支持就明说，不指路让用户自己绕。
5. **工程隔离**：切换/重新导入工程后，旧对话与待确认计划必须清空（`dialogBinding` 机制，验收保持覆盖）。
6. **全中文交互**：不得出现英文提示；不裸露 ID 和毫秒。
7. **测试材料自身错误要校准**：老项目 D01 指令 16:9 而预期写 9:16；C06 无备用素材；B05 未验证——不得将材料错误归因到 Agent。
