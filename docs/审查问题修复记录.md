# 审查问题修复记录

日期：2026-11-11。依据：《安全剪辑指令智能体研发任务书-彭宇鹏》。范围限于审查发现的问题、未识别指令的兜底及缺失的简要设计说明。

## 修复内容

- 歧义选择按操作序号保存目标 ID，再基于同一工程快照重算整条指令，不再替换原句。字幕正文、多个澄清步骤和已有选择均保留。
- 导入轨道时要求 locked 明确为布尔值，拒绝 null、缺失和错误类型；失败不替换当前工程。
- 操作前缀计算与最终计划使用同一校验引擎，前缀可以没有净变化；完整计划仍必须有实际变化，不放宽锁轨、重叠、素材边界等规则。
- 不支持或非法指令保留具体原因，明确本条指令未执行任何修改，并提供改写指引和适用的当前工程 ID 示例。不会只提交组合中已识别部分，不自动切换模型。
- 补充《设计取舍说明》，覆盖解析执行隔离、时间语义、原子性、防误操作、撤销和未实现范围。

## 回归验证

新增 internal/agent/review_regression_test.go，包含 5 组测试、19 个场景。先在原实现上验证失败，再修复并运行全量测试。覆盖字幕中重复指代词、引号与分号、多次澄清、非法锁定字段、无变化前缀、相互抵消的前缀、未知表达、中文数字、否定、组合未知目标、锁轨、非法时长、缺失字幕引号以及失败后的重新输入。

检查不仅断言返回状态，还核对实际工程内容与版本、确认前无修改、提交结果、整体撤销以及失败不生成撤销历史。

```powershell

```

未作任意自然语言兼容性承诺；真实模型联调和浏览器完整回归不包含在本轮验证结论中。
