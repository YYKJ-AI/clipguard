# 拉取后的离线验收

不需要模型账号、密钥、生产素材、数据库、Node.js 或 npm 安装。源码运行需要 Go 1.22+；独立二进制运行不需要 Go。首次从 GitHub 获取源码或下载 Go 需要网络，程序离线验收不访问外部服务。

## 启动

Windows PowerShell：`powershell -ExecutionPolicy Bypass -File scripts/start.ps1`。

macOS/Linux：`sh scripts/start.sh`。脚本只清理自身子进程的在线模型和产品身份配置，不修改用户系统环境。

浏览器打开 http://127.0.0.1:8090 。端口被占用时，Windows 加 `-Port 8091`；macOS/Linux 使用 `PORT=8091 sh scripts/start.sh`。

也可以执行 `go test ./...`，Windows 使用 `go build -o safety-edit-agent.exe .`，macOS/Linux 使用 `go build -o safety-edit-agent .` 后直接运行。直接运行会读取当前进程的可选模型环境变量；想强制离线请使用上述启动脚本。

## 八个必做场景

加载内嵌演示工程，每个独立场景前重新加载。修改成功和撤销都推进版本；拒绝或取消不推进版本。

| 场景 | 操作及检查 |
| --- | --- |
| 修改并撤销 | 输入 `把 clip-a 缩短 2 秒`。预览 5→3 秒，确认前仍为 5 秒；确认后 3 秒、版本 2；撤销后 5 秒、版本 3。恢复比较业务内容，版本不回退 |
| 多轨歧义 | 输入 `把第二段移到开头`。列出两个视频轨候选，不直接执行；选择后如与现有片段重叠则拒绝 |
| 锁轨 | 输入 `把 caption-lock 的字幕改为“不能修改”`。锁轨拒绝，字幕不变 |
| 非法参数 | 输入 `把 clip-a 缩短 99 秒`。拒绝且不改工程。未知操作、额外字段、负时长和越界源区间由 `go test ./...` 覆盖 |
| 旧计划失效 | 创建待确认计划后更换工程，旧卡片失效。自动化另覆盖相同工程同版本重载、并发提交及处理期间变化 |
| 取消删除 | 输入 `删除 clip-d`，点取消；结尾片段仍在，版本不变，没有“已删除”成功提示 |
| 批量失败 | 输入 `把 clip-a 缩短 1 秒；删除 caption-lock`。第二项锁轨导致整条失败，clip-a 仍为 5 秒 |
| 连续/重复撤销 | 连续提交两次修改，依次撤销两次，每次恢复一整条指令。重复确认/撤销请求的保护由自动化覆盖 |

## 扩展验收

1. **可视化差异**：输入 `把 clip-b 移到 12 秒处`，在左侧对比原位置和新位置；取消后差异区关闭，实际工程不变。
2. **编辑记录**：确认一次修改，在记录中展开查看实际字段变化；刷新页面仍能读回记录。取消、失败和仅预览不记为已执行。
3. **重做**：撤销后重做，整条指令恢复并继续推进版本。撤销后提交新编辑，旧重做分支消失。
4. **插入副本**：在插入区选择来源“开场镜头”、目标“视频轨道 2”、起点 12 秒。预览后确认，新增片段且来源不变；撤销移除新副本，重做恢复同一稳定 ID。也可输入 `在 video-2 轨道的 12 秒处插入 clip-a`。
5. **媒体预览**：选择开场片段，点击“使用演示封面”；拖动时间滑块，区间内显示封面及对应时间的字幕，区间外显示空态。可选本地视频或 PNG/JPEG/WebP/GIF；视频按 source_in_ms 定位，并在片段右端停止。文件不上传，不写入工程 JSON，刷新需重新绑定。

## 自动化

```text
go test -count=1 ./...
go build ./...
go vet ./...
```

页面逻辑回归额外需要 Node.js 18+，不需要 npm 依赖：

```text
node --test tests/web.test.cjs
node --check web/app.js
```

GitHub CI 将在 Windows、macOS、Linux 上检查 Go 1.22 和稳定版；Linux 稳定版额外执行竞态检测。工作流已提供，实际云端运行结果以仓库 Actions 为准。

开发者可选安装 Playwright CLI 重跑真实浏览器验收。先在项目目录创建 `output/playwright`，打开已启动的本地页面，执行 `playwright-cli run-code --filename tests/browser-acceptance.js` 和 `playwright-cli run-code --filename tests/browser-media-video.js`。脚本从当前页面读取服务地址，使用虚构工程；第二个脚本通过浏览器临时生成视频，不使用外部素材。自动化接受导入/重载提示，因此应使用独立测试浏览器会话。

## 在线模型单独验收

在线模型可选，使用验收方自己的兼容 Chat Completions 接口与密钥，见 README。页面“检查连接”会发起普通 JSON 和 SSE 两次咨询请求，不修改工程；显示“已连通”只代表协议验证，不等于任意自然语言正确。

对实际供应商仍应验证：咨询、四类编辑和插入、多操作、序数歧义、否定、改口、锁轨、未知 ID、参数越界、限流/认证失败、停止生成和断流。没有真实密钥时，协议与保护逻辑由本地模拟测试覆盖，真实供应商状态保留待验证。
