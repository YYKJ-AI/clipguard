## 流式边界

1. 咨询文字显示时标记“生成中 · 尚未完成”；此时内容可能被重试或最终校验替换，不代表执行成功。
2. 编辑计划不逐块显示原始 JSON、操作或确认按钮。只有完整内容通过严格字段检查、工程版本检查和 Go 预览计算后，才能出现确认卡片；仍须用户明确点击确认。
3. 上游必须正常 `finish_reason=stop` 并以 `[DONE]` 结束；断流、截断、未知操作、非法 JSON、超时、取消或处理期间工程变化均不能提交修改。格式修复只重试一次，先清空旧草稿。
4. 内容最多 256 KiB，上游 SSE 总读取最多 1 MiB，页面事件总读取最多 4 MiB；超限明确失败。不能把逐字动画当作真实流式输出。
5. 不支持 SSE 的供应商会得到明确失败；本次没有验证指定云端网关的 SSE 兼容性，也没有使用真实密钥。有限能力守卫和本地模拟测试不证明模型能理解任意自由表达。
6. 模型若没有在 message 之前声明 `status:answer`，不会提前展示该字段；页面先显示真实处理进度，再在完成后展示最终回复。当前提示词要求先输出状态，但供应商实际行为仍须单独联调。
