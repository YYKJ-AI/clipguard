## 其他完成项

- 四操作组合：跨轨移动、字幕文字、字幕时间、删除一次提交，字段正确，只推进一版，整体撤销恢复全部内容。
- 外部工程：改写工程 ID、轨道 ID、片段 ID 并打乱顺序后，通过真实文件导入、编辑、确认和撤销；对应 Go 回归已补齐。
- 真实下载：导出文件下载完成后重新选择该文件导入，工程内容与版本一致；刷新页面仍可恢复运行中会话。
- 上轮修复回归：澄清不会改写字幕中的“第二段”；无变化中间步骤不阻断后续有效操作；非法 locked 字段拒绝且保留当前工程。
- 本轮新增修复：start_ms 缺失或为 null 不再默认为零；片段字段显式 null 拒绝。非法导入后原待确认计划仍可确认，并能撤销。
- 未识别表达：组合中任一部分不支持时整条未提交；页面说明未执行任何修改及改写方法，不自动调用模型。
- 桌面 1440×1000、移动端 390×844 已检查；移动端时间轴和明细在容器内滚动，无整页横向溢出。主流程未捕获浏览器脚本异常。

浏览器中的 400、409、422、503 网络错误来自刻意执行的拒绝、重复请求和未配置模型场景，属于预期响应，不将其描述为“控制台零错误”。

## 实际验证与复现

本机从源码构建独立程序，使用 Microsoft Edge 和 Playwright CLI 0.1.24。API 与编辑引擎均为真实 Go 服务，未拦截或模拟。测试时显式关闭模型配置和产品认证配置，仅监听 127.0.0.1:18090；项目默认端口保持 8090。Node/浏览器工具仅用于验收，不是项目运行依赖。

```powershell
go test ./... -count=1
go vet ./...
go build ./...
go run .
```

全量测试、静态检查及构建均通过，前端 app.js 语法检查通过。新导入校验先用失败测试复现，再修复并完成全量回归。

可重复的四步现场演示：

1. 打开本地页面，加载演示工程；输入 `把 clip-a 缩短 2 秒`，核对新时长 3 秒，明确确认后查看版本与实际明细。
2. 点击撤销，核对恢复 5 秒，版本继续推进。
3. 输入 `把第二段移到开头`，展示两个轨道候选；选择 clip-b 后因重叠被拒绝，工程不变。
4. 输入 `把 caption-lock 的字幕改为“新文案”`，展示锁轨拒绝。补充输入 `删除 clip-d` 后取消，可演示取消保持原状态。

## 保留限制

离线模式仅支持 README 句式，不理解中文数字等自由变体。智谱完整在线联调仍受限流阻塞；竞态检测未执行，当前环境 CGO_ENABLED=0 且未配置 C 编译器。业务一致性、并发确认和重复请求已由既有自动化测试覆盖，但不把这些测试等同于竞态检测或容量压测。
