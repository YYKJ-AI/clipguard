## 真实浏览器检查

通过 Playwright CLI 0.1.24 驱动本机 Microsoft Edge，连接真实 Go HTTP 服务。未模拟网页 API 或编辑引擎。模型相关自动化使用测试服务，与真实模型验收分开。

| 场景 | 实际结果 |
|---|---|
| 加载演示工程 | 显示四轨、七片段及锁定字幕 |
| 同指令两次相对缩短 | 预览 5→3 秒；确认前明细仍 5 秒，确认后版本 2、时长 3 秒 |
| 整条撤销 | 两次缩短一起恢复至 5 秒，版本继续推进 |
| 删除后取消 | 生成删除预览，取消后完整工程和版本均不变 |
| 锁定字幕修改 | HTTP 422，明确说明锁轨，不修改工程 |
| 第二项操作失败 | 第一项缩短、第二项锁轨删除；整条拒绝，无部分提交 |
| “第二段”歧义 | 显示两个轨道候选；选择后再次校验，移动到被占用开头被拒绝 |
| 移动换轨、字幕文字、字幕时间、删除组合 | 四操作预览完整，确认仅推进一版；逐字段检查实际结果，撤销恢复全部片段内容 |
| 导出下载 | 下载完成，文件可解析，版本 3；导出不改变状态 |
| 重新导入下载文件 | 工程内容、版本与导出一致；旧历史及计划清空 |
| 页面刷新 | 同一浏览器会话恢复当前工程 |
| 重复确认 | 第一次提交成功，第二次 HTTP 409，不推进版本 |
| 同版本其他计划 | 其中一个提交后，其他旧计划 HTTP 409 |
| 同 ID、同版本重新导入 | 旧加载期间的计划 HTTP 409 |
| 取消后确认 | HTTP 409 |
| 连续两次撤销、重复撤销 | 两次独立撤销依次恢复历史并推进版本；重复请求 HTTP 409，未消费下一条历史 |
| 无历史撤销 | HTTP 409，不改变版本 |
| 桌面 1440×1000、手机 390×844 | 截图已检查，手机文档宽度 390 px；时间轴和明细在各自容器内滚动 |
| 最终构建加载、预览 | 浏览器控制台 0 错误、0 警告，显示 5→3 秒 |

拒绝场景的 HTTP 422/409 属于预期业务结果；浏览器网络面板中的对应失败请求不代表脚本异常。最初浏览器图标请求 404 已修复，并在新构建中验证不再出现。
